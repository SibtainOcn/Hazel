## 💡 功能：

- 从 YouTube、Instagram、TikTok、X、Reddit、SoundCloud 以及 [1000 多个其他网站](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) 下载音频和视频
- 粘贴一个链接、一次粘贴多个，或整个播放列表 / 频道，一键批量下载
- **Hazel Instant** - 从任意其他应用分享链接，即可按你预先设置的画质立即开始下载
- 当来源提供多条音轨时，可选择特定音轨
- 保存前编辑标题、作者以及文件类型 / 元数据
- 选择不同的下载格式和容器

### 搜索与播放
- **搜索** - 输入关键词而不是链接，即可搜索 YouTube、YouTube Music、SoundCloud、Bandcamp、Bilibili、Niconico、PRX 或 Rokfin，可选搜索建议
- **先播放再下载** - 直接在卡片上播放任意结果或链接，支持进度条、双击快进、全屏和画质选择，适用于 Hazel 能读取的任何网站
- **剪辑** - 只下载视频或音轨的一部分，在实时预览中选择范围
- **直播** - 从直播开头开始录制，或等待首映后再下载

### 处理
- **语言选择** - 以源视频提供的任意语言保存
- **SponsorBlock** - 去除赞助、片头及其他片段
- **章节** - 嵌入文件中，或按章节拆分为多个文件
- **字幕** - 使用你选择的语言

### 下载
- 支持长时间后台下载
- 可在卡片或通知中暂停、继续和取消
- 仅 Wi-Fi 模式 - 在开始时检查，已在进行的传输不会被中断
- 默认不限速，支持并行分片下载和可选限速
- 尚未下载的结果会保留在主屏幕上，直到你清除它们

### 隐私
- **无痕模式** - 下载不会加入媒体库，链接也不会被记录
- 无账号、无统计分析、不向任何地方发送数据（搜索建议默认关闭，开启后会将你输入的内容发送给 Google）

### 设置与个性化
- 深色和浅色主题，支持强调色
- 应用语言 - 英语、西班牙语、印地语、简体中文、巴西葡萄牙语、法语、德语、俄语、日语、印尼语以及跟随系统
- 独立的 yt-dlp 引擎更新 - Stable、Nightly 或 Master 渠道
- 离线视频转音频转换器
- **备份与恢复** - 设置、下载列表、队列、Cookie 和搜索历史

## ⬇️ 下载

对于大多数设备，建议安装 **arm64-v8a** 版本的 APK

- 从 [GitHub releases](https://github.com/SibtainOcn/Hazel/releases/latest) 下载最新稳定版
  - 安装 [预发布](https://github.com/SibtainOcn/Hazel/releases/) 版本，帮助我们测试新功能和改动

- 稳定版也可在 [F-Droid](https://f-droid.org/packages/com.hazel.android/) 获取

Hazel 将永远对所有人免费且开源。如果你喜欢它，欢迎通过 [GitHub Sponsors](https://github.com/sponsors/SibtainOcn) 或 [Buy Me a Coffee](https://www.buymeacoffee.com/sibtainocean) 支持本项目！

### 🔗  与第三方应用连接
应用的包名为 `com.hazel.android`。
