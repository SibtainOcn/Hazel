## 💡 功能特点:

- 从 YouTube、Instagram、TikTok、X、Reddit、SoundCloud 等 [1000+ 个受支持网站](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) 下载音视频
- 支持粘贴单个链接、多个链接或一键批量下载整个播放列表 / 频道
- **Hazel Instant** - 从任何其他应用分享链接，按预设画质立即启动下载
- 在多音轨视频中自由选择特定语言的原声音轨
- 保存前可编辑标题、作者及文件格式 / 元数据
- 选择不同的音视频下载格式与封装格式

### 媒体处理
- **语言选择** - 保存为源视频提供的任何语言音频（中文、英语、印地语、乌尔都语、阿拉伯语、德语等）
- **SponsorBlock** - 自动跳过赞助商片段、片头等非必要内容
- **章节** - 内嵌至媒体文件，或按章节拆分为独立文件
- **字幕** - 内嵌、独立保存或两者兼有，支持所选语言

### 下载管理
- 支持长期稳定的前台服务后台下载
- 在下载卡片或系统通知中暂停、继续与取消
- 仅限 Wi-Fi 模式 - 在开始时检测，避免中断已开始的任务

### 隐私安全
- **无痕模式** - 下载不加入历史记录，不记录链接
- 无需登录账号，无数据统计，绝不上传任何隐私

### 设置与个性化
- 深色与浅色主题，支持强调色自定义
- 应用语言 - 简体中文、英语、西班牙语、印地语、巴西葡萄牙语、法语、德语、俄语、日语、印尼语及系统默认
- 独立更新 yt-dlp 引擎 - 支持 Stable、Nightly 或 Master 更新通道
- 离线视频转音频工具

## ⬇️ 下载客户端

对于绝大多数设备，推荐安装 **arm64-v8a** 版本的 APK

- 从 [GitHub Releases](https://github.com/SibtainOcn/Hazel/releases/latest) 下载最新稳定版
