## 💡 คุณสมบัติเด่น:

- ดาวน์โหลดเสียงและวิดีโอจาก YouTube, Instagram, TikTok, X, Reddit, SoundCloud และ [เว็บไซต์อื่นๆ กว่า 1,000 แห่ง](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
- วางลิงก์เดียว หลายลิงก์ หรือดาวน์โหลดทั้งเพลย์ลิสต์ / ช่อง ได้ในคลิกเดียว
- **Hazel Instant** - แชร์ลิงก์จากแอปใดก็ได้ แล้วการดาวน์โหลดจะเริ่มต้นทันทีด้วยคุณภาพที่ตั้งไว้
- เลือกแทร็กเสียงภาษาที่ต้องการได้เมื่อวิดีโอต้นฉบับมีหลายภาษา
- แก้ไขชื่อ ผู้สร้าง และรูปแบบไฟล์ / ข้อมูลเมทาดาทาก่อนบันทึก
- เลือกรูปแบบไฟล์และคอนเทนเนอร์สำหรับดาวน์โหลดได้หลากหลาย

### การประมวลผลสื่อ
- **การเลือกภาษา** - บันทึกในภาษาใดก็ได้ที่วิดีโอมีให้ (ไทย, อังกฤษ, ญี่ปุ่น, เยอรมัน ฯลฯ)
- **SponsorBlock** - ข้ามสปอนเซอร์และส่วนที่ไม่ต้องการโดยอัตโนมัติ
- **ตอนย่อย (Chapters)** - ฝังลงในไฟล์ หรือแยกไฟล์ตามตอนย่อย
- **คำบรรยาย (Subtitles)** - ฝังลงในวิดีโอ หรือบันทึกแยกเป็นไฟล์ในภาษาที่เลือก

### การจัดการดาวน์โหลด
- รองรับการดาวน์โหลดเบื้องหลังอย่างต่อเนื่องและเสถียร
- หยุดชั่วคราว ดำเนินการต่อ และยกเลิกได้จากหน้าจอหรือการแจ้งเตือน
- โหมด Wi-Fi เท่านั้น - ตรวจสอบก่อนเริ่มเพื่อป้องกันการหยุดชะงัก

### ความเป็นส่วนตัว
- **โหมดไม่ระบุตัวตน** - ไม่บันทึกลงในประวัติ และไม่จดจำลิงก์
- ไม่ต้องมีบัญชี ไม่มีการติดตาม ไม่มีการส่งข้อมูลออกภายนอก

### การตั้งค่าและการปรับแต่ง
- ธีมมืดและสว่างพร้อมสีเน้นที่กำหนดเองได้
- ภาษาในแอป - ไทย, อังกฤษ, ญี่ปุ่น, จีน, สเปน, เยอรมัน และตามค่าเริ่มต้นของระบบ
- อัปเดตเครื่องยนต์ yt-dlp แยกอิสระ - ช่องทาง Stable, Nightly หรือ Master
- เครื่องมือแปลงวิดีโอเป็นเสียงแบบออฟไลน์

## ⬇️ ดาวน์โหลด

สำหรับอุปกรณ์ส่วนใหญ่ แนะนำให้ติดตั้ง APK เวอร์ชัน **arm64-v8a**

- ดาวน์โหลดเวอร์ชันเสถียรล่าสุดจาก [GitHub Releases](https://github.com/SibtainOcn/Hazel/releases/latest)
  - ติดตั้ง [เวอร์ชันทดสอบ](https://github.com/SibtainOcn/Hazel/releases/) เพื่อช่วยเราทดสอบฟีเจอร์ใหม่

- เวอร์ชันเสถียรมีให้บริการบน [F-Droid](https://f-droid.org/packages/com.hazel.android/) ด้วยเช่นกัน

Hazel จะเปิดให้ใช้งานฟรีและเป็นโอเพนซอร์สสำหรับทุกคนเสมอ หากคุณชอบ โปรดพิจารณา [สนับสนุนโครงการ](https://github.com/sponsors/SibtainOcn)!
