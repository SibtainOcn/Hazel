## 💡 主な機能:

- YouTube、Instagram、TikTok、X、Reddit、SoundCloud など [1000 以上の対応サイト](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) から動画・音声をダウンロード
- 単一URL、複数URL、または再生リスト / チャンネル全体をワンクリックで一括ダウンロード
- **Hazel Instant** - 他のアプリからリンクを共有するだけで、設定した品質で即座にダウンロード開始
- 複数言語の音声トラックが存在する場合に特定の音声を選択可能
- 保存前にタイトル、投稿者名、ファイル形式 / メタデータを編集可能
- 動画・音声の各種フォーマットやコンテナを自由に選択

### メディア処理
- **言語選択** - 動画ソースが提供する任意の言語で保存（日本語、英語、スペイン語、ドイツ語など）
- **SponsorBlock** - スポンサー広告やオープニングなどの不要な区間を自動スキップ
- **チャプター** - ファイル内にチャプターを埋め込むか、チャプターごとに個別分割して保存
- **字幕** - 映像への焼き付け、別ファイル保存、またはその両方に対応

### ダウンロード管理
- フォアグラウンドサービスによる長時間のバックグラウンドダウンロード対応
- カードや通知から一時停止・再開・キャンセルが可能
- Wi-Fi のみモード - 開始時に確認し、進行中の通信を急激に遮断しない設計

### プライバシー
- **シークレットモード** - 履歴に追加されず、リンクも保存されません
- アカウント不要、トラッキングなし、外部への送信なし

### 設定とカスタマイズ
- ダーク/ライトテーマ、アクセントカラー対応
- アプリ言語 - 日本語、英語、スペイン語、中国語、ドイツ語、フランス語など、およびシステム標準
- yt-dlp エンジンの単独更新 - Stable / Nightly / Master チャンネル
- オフライン動画・音声変換ツール

## ⬇️ ダウンロード

ほとんどの端末では **arm64-v8a** 版の APK インストールを推奨します

- [GitHub Releases](https://github.com/SibtainOcn/Hazel/releases/latest) から最新の安定版をダウンロード
  - 新機能のテストに協力いただける場合は [プレリリース版](https://github.com/SibtainOcn/Hazel/releases/) をお試しください

- 安定版は [F-Droid](https://f-droid.org/packages/com.hazel.android/) からも入手可能です

Hazel は誰にとっても常に無料でオープンソースです。気に入っていただけたら、ぜひ [プロジェクトの支援](https://github.com/sponsors/SibtainOcn) をご検討ください！
