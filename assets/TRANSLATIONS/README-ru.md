## 💡 Возможности:

- Скачивание аудио и видео с YouTube, Instagram, TikTok, X, Reddit, SoundCloud и [более 1000 других сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)
- Вставка одной или нескольких ссылок, либо целых плейлистов / каналов для пакетного скачивания в один клик
- **Hazel Instant** - делитесь ссылкой из любого приложения, и скачивание начнется мгновенно с выбранным качеством
- Выбор определенных аудиодорожек, если видео содержит звук на нескольких языках
- Редактирование названия, автора и формата / метаданных перед сохранением
- Выбор различных форматов и контейнеров для загрузки

### Обработка
- **Выбор языка** - сохранение на любом языке, предоставленном видео (русский, английский, немецкий, испанский и др.)
- **SponsorBlock** - автоматический пропуск спонсорских вставок и заставок
- **Главы** - встраивание в файл или разбивка на отдельные файлы по главам
- **Субтитры** - вшивание, сохранение отдельным файлом или оба варианта на выбранных языках

### Загрузки
- Поддержка длительной фоновой загрузки через стабильную службу
- Пауза, возобновление и отмена прямо из карточки или уведомления
- Режим «Только Wi-Fi» - проверка перед стартом, чтобы не прерывать текущую передачу

### Конфиденциальность
- **Режим инкогнито** - загрузки не попадают в историю, ссылки не сохраняются
- Без аккаунтов, без телеметрии, данные никуда не отправляются

### Настройки и оформление
- Темная и светлая темы с акцентным цветом
- Языки интерфейса - русский, английский, испанский, немецкий, французский, японский и системный по умолчанию
- Независимое обновление движка yt-dlp - каналы Stable, Nightly или Master
- Офлайн-конвертер видео в аудио

## ⬇️ Скачать

Для большинства устройств рекомендуется устанавливать APK для архитектуры **arm64-v8a**

- Скачать актуальную стабильную версию в [GitHub Releases](https://github.com/SibtainOcn/Hazel/releases/latest)
  - Установить [предварительные версии](https://github.com/SibtainOcn/Hazel/releases/) для тестирования новых функций

- Стабильные версии также доступны в [F-Droid](https://f-droid.org/packages/com.hazel.android/)
